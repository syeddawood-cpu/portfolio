SYED DAWOOD HUSSAIN — FRONT-END DEVELOPER PORTFOLIO

HOW TO VIEW
1. Extract this ZIP file.
2. Open index.html in a browser (Chrome recommended).
3. Use the navigation to visit Home, About and Contact.
4. Scroll to Selected Projects and click "Explore website" to open each standalone website.

WHAT'S INCLUDED
- 3 portfolio pages: index.html, about.html, contact.html
- 24 individual multi-section website concepts in /projects/
- Responsive layouts for desktop, tablet and mobile
- HTML5, CSS3 and JavaScript
- Working portfolio project links, navigation anchors and category filters
- Remote Unsplash photography and Google Fonts (internet connection required for images/fonts)
